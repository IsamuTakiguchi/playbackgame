# 逆再生ゲーム (Reverse Playback Game)

逆再生された音声を出題者がマネして発声し、それをもう一度逆再生すると元の言葉に
聞こえる——という遊びをブラウザだけで完結させるパーティゲームです。

## 遊び方

1. **お題を作る**: 元の言葉をマイクで録音（または音声ファイルを読み込み）、答えを付けて保存。
2. **ゲームを始める**: ランダムに 1 問選ばれ、出題者がその**逆再生**を聞きます。
3. **マネを録音**: 出題者が逆再生の音をマネして発声し、録音します。
4. **答え合わせ**: マネ音声を逆再生して再生。うまくいけば元の言葉に聞こえます。回答者が当てます。

## 技術構成

- **Vite + TypeScript**（フレームワーク無しのバニラ DOM）
- **Web Audio API + MediaRecorder**: 録音・デコード・逆再生・再生をブラウザ内で完結
- **IndexedDB**（`idb`）: お題（音声 Blob + メタ）を端末内に保存。バックエンド不要
- 逆再生は `AudioBuffer` の各チャンネルのサンプル列を逆順にするだけ（`src/audio/reverse.ts`）

## セットアップ

```bash
npm install
npm run dev      # http://localhost:5173 を開く
```

- マイク録音には **セキュアコンテキスト**が必要です（`localhost` は OK、本番は HTTPS）。
- 録音形式はブラウザ依存ですが、保存時に **WAV** へ正規化しています。

## 注意・既知の制約

- **iOS Safari**: 再生は必ずタップ操作起点で行ってください。サイレント（消音）スイッチが
  ON だと Web Audio がミュートされます。
- マイクの `echoCancellation` / `noiseSuppression` / `autoGainControl` は無効化しています
  （マネ音声を歪ませず、逆再生の忠実度を保つため）。
- データは端末内（IndexedDB）にのみ保存されます。端末・ブラウザをまたいだ共有はしません。
